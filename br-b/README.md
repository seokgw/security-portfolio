# 소통과 사용 돌아보기 · BR-B

과제 10 논문의 근거 구분을 반영한 휴대전화 사용·외부 소통·환경 자기점검 앱입니다. 사용시간만으로 점수·위험도·스트레스를 진단하지 않습니다.

## 실행

공개 앱: https://seokgw.github.io/security-portfolio/br-b/

점검과 결과 확인은 로그인 없이 사용합니다. 날짜별 기록 저장·조회에는 GitHub 로그인이 필요합니다. 저장 버튼을 눌러 완료 안내가 나온 기록은 BR-B 전용 Supabase DB에 저장됩니다. 브라우저 데이터를 지워도 같은 GitHub 계정으로 다시 로그인하면 저장 기록을 불러올 수 있습니다. 저장하지 않은 입력은 복구되지 않습니다.

1. 날짜·사용시간(0~24)·주요 목적·평소 외부 소통 빈도를 입력합니다.
2. 스트레스·소통·휴식 체감, 수면시간, 사용 시간대·기분과 14개의 환경 요소 중 필요한 항목을 선택합니다. 추가 항목은 선택 사항입니다.
3. 결과 확인 후 로그인하고 저장합니다. 날짜별 목록에서 기록을 열어 수정하거나 이전 날짜와 비교하고 CSV로 내려받을 수 있습니다.

빈 값, 음수, 문자, 24 초과는 입력 안내가 표시됩니다. 초기화하면 결과가 숨겨집니다.

## 연구와 구현

논문 제목: 병사 휴대전화 사용 허용과 외부 소통 및 심리적 스트레스에 관한 공개자료 연구.

소통의 편익과 대화 단절·과의존 관련 우려를 함께 검토하고, 인과 경로를 판단하기 어렵다는 연구의 한계를 반영했습니다. 조건별 문장은 입력을 돌아보기 위한 구현상 안내이며 논문에서 검증한 진단 규칙이 아닙니다.

공개 주소: https://seokgw.github.io/security-portfolio/br-b/

포트폴리오: https://seokgw.github.io/security-portfolio/br-a/site/#work

ZIP의 `index.html`은 로컬 점검에 사용할 수 있습니다. GitHub 로그인·DB 저장은 공개 앱에서 사용하세요. 클라우드 기능에는 인터넷이 필요합니다.

DB는 `yebnfcjjirwynnqzoxag` 프로젝트의 `brb_daily_records` 테이블을 사용합니다. RLS와 본인 사용자 ID 정책을 적용하고 비로그인 권한을 차단했습니다. 공개 코드의 publishable key는 브라우저용 공개 키이며, 관리 토큰·OAuth Client secret·DB 비밀번호는 포함하지 않습니다. Supabase 인증은 로그인 계정 정보를 처리하지만 앱 화면과 CSV에는 이메일·이름을 표시하지 않습니다.
