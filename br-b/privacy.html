BR-B 개인정보 처리 안내

적용일: 2026-10-02 · 운영자: 석근욱

로그인과 자기점검 기록

로그인 없이 점검하는 입력은 앱 화면에서 처리합니다. 저장 버튼을 누른 기록만 BR-B 전용 Supabase DB로 전송합니다. 저장 항목은 날짜, 휴대전화 사용시간·목적, 소통 빈도, 선택한 환경 요소와 스트레스·소통·휴식 체감, 수면시간, 사용 시간대·기분입니다. 자기보고 점검이며 의료 진단에 사용하지 않습니다.

Google 또는 GitHub 로그인은 Supabase Auth가 처리합니다. 로그인 공급자의 사용자 식별자, 이메일, 기본 프로필(이름·사진 등)이 계정 식별과 인증에 사용될 수 있습니다. 앱은 Google의 기본 프로필·이메일·openid 범위만 요청하며 Gmail·Drive 데이터에 접근하지 않습니다. 계정 이름·이메일을 기록 목록이나 CSV에 표시하지 않습니다.

저장과 접근

기록은 본인 계정의 날짜별 조회·수정·비교에 사용합니다. 기록 DB는 서울 리전의 Supabase 프로젝트를 사용합니다. RLS 정책으로 본인 사용자 ID의 기록에만 접근하도록 제한하며 비로그인 기록 접근은 허용하지 않습니다. 웹사이트는 GitHub Pages로 배포합니다. Google·GitHub·Supabase의 인증 처리에는 각 서비스의 개인정보 정책도 적용됩니다.

인증 세션은 브라우저에 저장됩니다. 기록 본문은 DB에 보관되므로 로그아웃하거나 브라우저 데이터를 지워도 자동 삭제되지 않습니다. 기록의 자동 만료 기능은 없습니다. 같은 계정으로 로그인하면 CSV를 내려받거나 기록을 수정할 수 있습니다. 계정·기록 삭제 요청은 운영자에게 문의하고 본인 확인 후 처리합니다. 공개 문의에는 점검 기록, 이메일, 토큰이나 비밀번호를 게시하지 마세요.

선택과 문의

추가 체감 항목은 선택 사항이며 로그인·저장 없이 점검 기능을 사용할 수 있습니다. 로그아웃하면 해당 브라우저의 앱 로그인 세션이 해제됩니다. 같은 확인된 이메일의 소셜 계정은 Supabase에서 연결될 수 있으며, 다른 이메일의 계정은 별도 기록을 사용합니다.

로그인 관련 문의는 Google 로그인 동의 화면의 지원 연락처를 이용할 수 있습니다. 운영자 정보: GitHub 프로필.
