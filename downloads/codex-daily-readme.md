# 코덱스 일상용 실행 안내

Windows용 학습 프로젝트입니다. Node.js 24.19.0을 먼저 설치하세요.
Node.js 공식 다운로드: https://nodejs.org/en/download

1. ZIP 전체를 압축 해제합니다.
2. 실행.cmd를 더블 클릭합니다.
3. 서버 시작 안내가 나오면 http://127.0.0.1:5192/ 를 엽니다.
4. 종료할 때 실행 창에서 Ctrl+C를 누릅니다.

실행.cmd와 codex-daily 폴더를 같은 위치에 두세요. npm install은 필요하지 않습니다.
기본 실행은 외부 SDP/XDR·AI 서비스 미연결 상태입니다. 개인 인증정보는 포함하지 않습니다.
PC 상태 조회는 사용자가 화면에서 요청합니다. 다른 PC에서의 실행은 미검증입니다.
자세한 안내는 codex-daily/START_HERE.md를 참조하세요.
