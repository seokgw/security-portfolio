# 과제 5 이름 가린 비교

| 항목 | 작업자 A | 작업자 B |
|---|---|---|
| 주요 역할 | fresh/stale/error 로직, 문구, 배지, 로직 테스트 | 과제 5 폴더 분리, 브라우저·경계 검증, 보고서 |
| 사용 도구 | Node 내장 test runner | Node 내장 test runner, Chrome, Playwright |
| 확정 PASS | 4/10 | 10/10 |
| 오류 회차 | 구현·로직 검사 FAIL 0 | 제품 FAIL 0; 검증 스크립트 단위 가정 오류 1회 |
| 인수인계 누락 | 실제 브라우저 미검증, 과제 4 폴더에 직접 작업 | 과제 5 전용 폴더로 보정, 나머지 6개 화면 검사 완료 |
| 결과 | 핵심 개선 구현 완료 | 과제 4 보존·과제 5 분리, 최종 검증·공개 보고서 완료 |

작업자 A와 B의 호출 수는 환경의 도구 호출 단위가 달라 성능 비교 수치로 사용하지 않았다. 동일한 고정 검사 통과 여부와 재현 증거를 기준으로 비교했다.
