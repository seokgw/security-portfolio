01AUTHENTICATION

인증 흐름 분석

로그인·SSO·Cookie 및 권한 처리 흐름을 분석했습니다.

상황
로그인 또는 SSO 과정에서 특정 사용자 조건에 따라 접근하지 못하는 문제가 발생했습니다.
행동
요청 흐름, return URL, Cookie, 인증 유효시간과 사용자 권한 처리 로직을 추적했습니다.
결과
문제가 발생하는 조건과 처리 위치를 파악하고 수정할 수 있었습니다.
