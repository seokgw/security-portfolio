PROJECT 01 · 2026.08.24

Packet Tracer 네트워크 통합 구성

네트워크 기초 종합과제 · AEGIS 팀 · 보고서상 역할: 팀장

Cisco Packet Tracer에서 서로 다른 라우팅 구간과 내부 LAN, 본사·지사 구간을 연결하고 이중화·접근통제·주소 변환·VPN을 한 토폴로지에서 검증했습니다.

라우팅과 이중화

  • EIGRP AS 100과 OSPF Area 0 구성
  • 상호 재분배 후 최장 구간 Ping 검증
  • HSRP Active/Standby와 가상 게이트웨이 확인

세그먼트와 접근통제

  • VLAN 10·20·30 및 802.1Q 서브인터페이스 구성
  • FTP 차단, WEB 허용, ICMP 차단 ACL 검증
  • 기타 트래픽 허용 조건 확인

주소와 연결

  • DHCP와 Static NAT 매핑
  • NAT Translation 및 외부 통신 확인
  • 본사·지사 Site-to-Site VPN과 tracert 검증

오류 해결

  • VPN과 ACL 정책 번호 충돌 수정
  • EIGRP·OSPF 재분배 오류 확인 및 해결
  • 설정값보다 실제 통신 결과를 기준으로 완료 판정

검증 결과
Routing Table, Ping, 서비스 접속, NAT Translation, HSRP 상태와 VPN 통신이 보고서의 예상 결과와 일치했습니다.

팀 과제이므로 세부 기능별 개인 담당 범위는 보고서에서 확인되지 않습니다. 개인 역할은 팀장으로만 표시했습니다.

PROJECT 02 · 2026.09.29

GNS 보안 인프라 구축과 통합 검증

보안 인프라 운영관리 · 내·외부망 분리, 탐지·관제·모니터링·침투검증

내부망과 외부망을 분리하고 보안 장비, 탐지 시스템, 모니터링, 중앙 로그와 내부 서비스를 연계했습니다. 구축 여부만 나열하지 않고 탐지 이벤트와 접속 상태, 로그, CTF 결과로 동작을 확인했습니다.

네트워크 분리와 경계 통제

  • 내·외부 구간 및 VLAN 10 Network·20 System·30 PenTest 분리
  • ASA 방화벽 5개 정책 적용
  • pfSense OpenVPN UDP 1194 연결 확인

침입 탐지와 호스트 보호

  • Snort ICMP Recon·SYN Scan·SSH Brute Force 정책
  • Wazuh Rocky Web 에이전트 active 확인
  • OSSEC Rule 550 Level 7 파일 무결성 탐지

운영 모니터링과 로그

  • Zabbix 서버 가용성 확인
  • Percona PMM의 MySQL·PostgreSQL 모니터링
  • LogAnalyzer에서 TCP·UDP 514 중앙 Syslog 153건 조회

서비스와 침투 검증

  • 내부 DNS 기반 통합 포털 접근
  • Wazuh·OSSEC·Zabbix·PMM·Snort·로그 메뉴 연계
  • Earth VM User Flag와 Root Flag 획득

검증 결과
구간 분리, 경계 통제, 탐지·관제, 운영 모니터링, 서비스 연계와 침투 검증의 여섯 평가 영역이 모두 충족으로 기록됐습니다.

주소와 수치는 격리된 실습 환경의 기록입니다. 공개 포트폴리오에는 계정·비밀번호·비밀키를 포함하지 않습니다.
