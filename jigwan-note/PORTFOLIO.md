# 직관노트 · 사용자 의견을 반영한 야구 기록 서비스

야구 직관 경험을 경기 결과·사진·후기로 남기고 관람 통계를 확인하는 개인용 웹앱입니다. 기능 구현에서 끝내지 않고 친구의 의견을 바탕으로 첫 진입과 입력 방식을 바꾸고, 배포 환경에서 실제 계정으로 저장·재로그인·사진·인증 흐름을 확인했습니다.

- 기간: 2026년 10월, 검증 기준일 2026-10-19
- [공개 서비스](https://jigwan-note.vercel.app/)

## 문제와 개선

| 받은 의견·발생한 문제 | 반영한 내용 | 확인 범위 |
|---|---|---|
| 첫 화면이 로그인이라 이용을 망설임 | 소개 화면과 로그인 없는 샘플 체험 추가 | 서비스 소개 → 샘플 대시보드 진입 |
| 구장을 직접 입력하기 번거로움 | 주요 구장 선택 목록 + 기타 직접 입력 | 새 경기 기록의 구장 입력 |
| 매번 응원팀을 입력해야 함 | 계정별 응원팀 저장과 새 기록 자동 입력 | 로그아웃·재로그인 후 유지 |
| 로그인 후 DB 연결 오류 | 직관노트 스키마의 API 노출 설정 보완 | 실제 계정 기록 저장·조회 |
| 기존 DB를 다른 앱도 사용 | 기존 프로젝트 안에서 스키마·테이블·사진 저장소 분리 | plan-do-see 기존 내용 보존 |

친구의 의견은 변경 전 피드백입니다. 개선 후 친구의 재사용 평가는 아직 받지 않았으며 만족도 상승이나 사용자 수 증가를 주장하지 않습니다.

## 제공 기능과 구조

- 이메일 회원가입·인증·로그인·로그아웃과 세션 유지
- 경기 기록 등록·조회·수정·삭제, 날짜·구장·팀·점수·좌석·후기 입력
- 사진 최대 3장, 비공개 Storage 경로 저장과 서명 URL 표시
- 승률·방문 구장 통계, 검색·필터, 모바일 화면 대응
- 구장 선택과 계정별 응원팀 설정
- HTML·CSS·JavaScript / GitHub / Vercel / Supabase Auth·PostgreSQL·Storage

개인 기록은 `jigwan.jigwan_watch_records`의 소유권 RLS로 제한하고 사진은 비공개 `jigwan-watch-photos` bucket에 보관합니다. 응원팀은 사용자 메타데이터의 앱 전용 항목으로 관리합니다. 샘플 모드는 메모리에서만 동작하며 Supabase에 기록을 쓰지 않습니다. 이 설명은 구현 구조이며 종합 보안 감사 완료를 의미하지 않습니다.

## 본인 판단과 AI 수행

| 구분 | 수행 내용 |
|---|---|
| 사용자 | 서비스 주제·필요 기능 결정, 친구 피드백 전달과 개선 요청, 응원팀 기능 요청, 공개 승인, 기존 데이터 보존과 비용 방향 결정, 테스트·임시 메일·계정 정리 승인 |
| AI | 화면·기능 구현, GitHub·Vercel·Supabase 연결, 오류 수정, 실제 계정 테스트와 증거 확인, 발표·제출 자료 작성 |

AI의 구현과 기술 검증을 사용자가 직접 코딩하거나 시험한 경험으로 표기하지 않습니다.

## 실제 배포 환경에서 확인한 결과

2026-10-19 사용자 요청에 따라 AI가 테스트 전용 계정과 자체 생성 사진으로 확인했습니다.

- 응원팀 ‘한화 이글스’를 저장하고 로그아웃·재로그인해 유지 및 새 기록 자동 입력 확인
- 경기 5:3 승리 등록 → 새로고침 조회 → 2:3 패배 수정, 승률 100% → 0% 반영 확인
- 사진 업로드·새로고침 후 표시, 기록 삭제 후 DB·Storage 잔여 0개 확인
- 신규 가입용 임시 메일에서 인증 메일 1건 수신과 인증 링크 처리·서버 인증 완료 확인
- 390×844 화면에서 메뉴·상세·사진과 가로 넘침 없음 확인
- 테스트 계정 2개·기록·사진·임시 수신함 정리 완료, 기존 사용자 데이터 보존

기능 검증용 계정은 관리자 작업으로 인증된 상태로 만들었고, 메일 검증은 별도의 실제 신규 가입으로 진행했습니다. 삭제 확인창 자동화의 시간 초과는 브라우저 요청 로그와 DB·Storage 조회로 후속 확인했습니다. 메일 결과는 해당 임시 수신함 1회 기준이며 모든 메일 서비스의 전달 보장은 아닙니다. 모바일은 뷰포트 검증이며 실물 기기 테스트는 아닙니다.

## 확인하는 방법

1. [서비스](https://jigwan-note.vercel.app/)에서 ‘샘플 기록 둘러보기’를 선택합니다.
2. 대시보드·히스토리·새 기록·응원팀 설정을 살펴봅니다. 샘플 데이터는 계정에 저장되지 않습니다.
3. 실제 저장은 회원가입·메일 인증·로그인 후 이용합니다. 정리한 테스트 계정의 자격 증명은 제공하지 않습니다.
