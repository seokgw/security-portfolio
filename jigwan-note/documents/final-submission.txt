이번에 만든 것
야구 직관 경험을 경기 결과·사진·후기로 남기는 웹앱 ‘직관노트’를 만들고 공개 배포했습니다. 회원가입과 로그인, 경기 기록 등록·조회·수정·삭제, 사진 업로드, 승률과 방문 구장 통계를 구현했습니다. 로그인 전에 소개 화면과 샘플 기록을 둘러볼 수 있고, 구장을 목록에서 선택하거나 직접 입력할 수 있습니다. 계정별 응원팀을 저장하면 새 기록에 자동으로 입력됩니다. 실제 테스트 계정으로 재로그인 후 응원팀 유지, 기록과 사진 저장, 인증 메일 수신을 확인했습니다.

확인하는 방법 · 3단계 이내
1. https://jigwan-note.vercel.app/ 에 접속해 ‘샘플 기록 둘러보기’를 선택합니다.
2. 대시보드와 기록 목록에서 경기·사진·통계를 살펴보고, 새 기록과 응원팀 설정에서 구장 선택 및 팀 자동 입력을 확인합니다. 샘플 체험은 실제 계정에 저장되지 않습니다.
3. 실제 저장은 회원가입 후 이메일 인증과 로그인을 거쳐 이용합니다. 응원팀을 저장하고 경기 기록과 사진을 등록한 뒤, 재로그인하여 유지되는지 확인할 수 있습니다.

바뀐 점과 그 이유
친구가 ‘첫 화면부터 로그인이라 거부감이 든다’고 해서 소개 화면과 로그인 없는 샘플 체험을 추가했습니다. ‘구장을 선택할 수 있으면 좋겠다’는 의견을 반영해 구장 선택 목록과 기타 직접 입력을 제공했습니다. 매번 팀을 입력하는 번거로움을 줄이기 위해 응원팀 설정과 새 기록 자동 입력도 추가했습니다. 로그인·회원가입 안내 문구와 DB 연결 문제를 보완했고, 기존 plan-do-see 데이터는 보존하면서 직관노트의 저장 공간을 분리했습니다.

AI에게 맡긴 일과 내가 판단한 일
저는 서비스의 주제와 필요한 기능을 정하고, 친구의 피드백을 전달해 소개·체험 화면과 구장 선택 기능을 요청했습니다. 응원팀 설정, 페이지 공개, 기존 데이터 보존과 추가 비용을 피하는 방향도 제가 결정했습니다. AI에는 화면과 기능 구현, GitHub·Vercel·Supabase 연결, 오류 수정, 테스트 계정 생성과 실제 흐름 검증을 맡겼습니다. 임시 메일 사용과 테스트 계정 삭제는 제가 승인했습니다. 기술 검증은 AI가 수행했으며, 개선 후 친구의 재사용 평가는 아직 받지 않았습니다.

다음에 할 일
개선된 화면을 친구에게 다시 사용해 보게 하고, 첫 이용과 기록 작성 과정에서 남은 불편을 확인하겠습니다. 비밀번호 재설정, 개인정보 안내와 계정 삭제 흐름을 보완하고, 실제 휴대폰과 여러 브라우저·메일 서비스에서도 확인 범위를 넓힐 계획입니다. 현재 모바일 검증은 390px 화면 크기에서 진행한 결과입니다.
