# 완성 이미지 권한 및 안전 검사

| 파일 | 화면비 | 문구 | 권한 근거 |
|---|---|---|---|
| `evidence/sample-square.png` | 1:1 | 오늘도 한 걸음 | 본인 제작 이미지(코드로 만든 단순 그라디언트) |
| `evidence/sample-feed.png` | 4:5 | 작은 순간을 기록해요 | 본인 제작 이미지(코드로 만든 단순 그라디언트) |
| `evidence/sample-story.png` | 9:16 | 나답게, 더 멀리 | 본인 제작 이미지(코드로 만든 단순 그라디언트) |

세 파일은 외부 사진이나 제3자 저작물을 사용하지 않았다. 앱과 같은 Canvas 재인코딩 방식으로 생성해 원본 EXIF/GPS를 승계하지 않는다. Pillow의 이미지 정보 조회에서 EXIF/GPS 항목 0건을 확인한다.

## AEGIS 추가 검증 이미지

`docs/evidence/aegis/`의 1:1, 4:5, 9:16 완성 이미지에는 사용자가 테스트 목적으로 제공한 `AEGIS 팀 로고.png`를 사용했다. 이미지의 본인 제작 여부와 공개 이용 권한은 사용자 확인이 필요하며, 확인 전에는 `본인 제작 이미지`라고 표시하지 않는다. 세 완성 PNG는 재인코딩 후 EXIF/GPS 0건, 추가 info key 0건을 확인했다.
