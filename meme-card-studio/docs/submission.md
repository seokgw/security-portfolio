# 제출용 문구

## 짧은 확인 방법

**위치**  
공개 결과물 URL의 짤·카드 스튜디오 첫 화면에서 이미지·문구 편집기와 미리보기를 확인한다.

**행동**  
1. PNG/JPEG 이미지를 불러온다.
2. 문구, 위치, 색상과 화면비를 변경한다.
3. 파일 다운로드와 템플릿 저장·불러오기를 확인한다.

**통과 모습**  
문구 변경이 즉시 반영되고 미리보기와 다운로드 파일의 crop·문구 위치·줄바꿈이 일치하며, 저장한 템플릿이 새로고침 뒤에도 유지된다.

**안 될 때 모습**  
지원하지 않는 파일이나 잘못된 JSON에서 명확한 오류가 없거나, 오류 뒤 기존 편집 내용 또는 템플릿이 사라지면 실패다.

## AI와 나의 판단

**AI에게 맡긴 일**  
Canvas 공통 렌더러, 이미지 검증, 템플릿 CRUD·JSON 검증, 반응형 UI, 자동 테스트와 검증 문서의 구현을 맡겼다.

**직접 판단한 일**  
차분한 스튜디오형 디자인, 세 화면비의 출력 크기, 상대 좌표 방식, 테스트용 자체 제작 그라디언트와 한국어 오류 문구를 과제 목적에 맞게 선택했다.

**AI 제안을 따르지 않은 일**  
AI 제안을 따르지 않은 일은 없었으며, 제안을 검토한 뒤 과제 요구사항에 맞는 내용만 적용했다.
