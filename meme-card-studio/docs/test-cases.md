# 극단 입력 검사 기록

검사 환경: Chromium, 로컬 정적 서버. 아래 12건은 동일한 `renderCanvas` 경로로 미리보기와 저장을 확인했다.

| 번호 | 검사 입력 | 예상 결과 | 실제 결과 | 판정 |
|---:|---|---|---|:---:|
| 1 | 500자 이상의 긴 한글 문장 | Canvas 폭에서 자동 줄바꿈, 앱 정상 | 글자 단위로 자동 줄바꿈되고 편집 지속 | PASS |
| 2 | `한글 English 123 카드` 혼합 | 문자 누락 없이 표시 | 혼합 문구 정상 표시 | PASS |
| 3 | `첫 줄\n둘째 줄\n셋째 줄` | 직접 줄바꿈 3줄 유지 | 3줄로 동일 렌더링 | PASS |
| 4 | `오늘도 최고예요 🌟🚀` | 가능한 시스템 폰트로 이모지 표시 | 이모지 포함 렌더링, 오류 없음 | PASS |
| 5 | 빈 문자열 | 텍스트 없이 이미지만 표시 | 오류 없이 배경/이미지만 표시 | PASS |
| 6 | 공백 없는 300자 URL 형태 문자열 | Canvas 폭에서 강제 줄바꿈 | 문자 단위로 안전하게 줄바꿈 | PASS |
| 7 | 600×1200 세로형 자체 제작 이미지 | 세 비율에서 중앙 cover crop | 빈 여백 없이 중앙 crop | PASS |
| 8 | 1600×700 가로형 자체 제작 이미지 | 세 비율에서 중앙 cover crop | 빈 여백 없이 중앙 crop | PASS |
| 9 | 알파 채널이 있는 투명 PNG | 배경 위에 투명도 합성 | 투명 영역 정상 합성 | PASS |
| 10 | 1×1 PNG | 확대 후 앱 오류 없음 | Canvas 전체에 확대 렌더링 | PASS |
| 11 | 6000×4000 JPEG | 20MB 이하 파일 로드 및 저장 | 로드·crop·다운로드 정상 | PASS |
| 12 | 편집 중 GIF 및 손상 JSON 입력 | 명확히 거부하고 기존 상태 유지 | 오류 메시지 표시, 문구·비율·템플릿 유지 | PASS |

## 실제 결함 수정 기록

- 동일 검사 입력: 저장소 루트에서 `node meme-card-studio/scripts/build.js` 실행(11번의 큰 이미지 등 배포 파일을 검증하기 위한 빌드 단계)
- 수정 전: **FAIL** — 스크립트가 현재 작업 디렉터리에서 `styles.css`를 찾아 `ENOENT`로 종료되었다.
- 원인: 프로젝트 위치가 아니라 명령을 실행한 위치를 기준으로 입력 파일 경로를 계산했다.
- 수정 내용: `import.meta.url`에서 프로젝트 루트를 계산해 모든 입·출력 경로를 절대 경로로 구성했다.
- 수정 후: **PASS** — 같은 명령을 저장소 루트에서 실행해 `meme-card-studio/dist/index.html`과 정적 자산이 생성되었다.

6번의 긴 무공백 문자열은 `Array.from()` 기반 코드 포인트 단위 자동 줄바꿈 테스트로 회귀를 방지한다.
