# 과제 3 제출 입력 내용

## 결과물 URL (필수)

https://seokgw.github.io/security-portfolio/meme-card-studio/

## 소스 저장소 URL (필수)

https://github.com/seokgw/security-portfolio/tree/main/meme-card-studio

## 재현·통과 확인 4가지 (권장)

어디로 가나요: 공개 결과물 URL에 접속하면 로그인 없이 짤·카드 스튜디오의 이미지·문구 편집 화면과 Canvas 미리보기가 바로 열립니다.

무엇을 하나요(3단계 이내): 1) PNG/JPEG 이미지를 불러옵니다. 2) 문구·위치·크기·색상과 1:1·4:5·9:16 화면비를 변경합니다. 3) PNG/JPEG 다운로드와 템플릿 저장·불러오기·JSON 내보내기/가져오기를 확인합니다.

무엇이 보이면 통과: 편집값이 별도 적용 버튼 없이 즉시 Canvas에 반영되고, 미리보기와 다운로드 파일의 이미지 잘림·문구 위치·줄바꿈이 일치하며, 저장한 템플릿이 새로고침 뒤에도 유지되면 통과입니다.

안 될 때: 지원하지 않는 파일이나 손상·필수 항목 누락 JSON에서 명확한 오류 메시지가 나오지 않거나, 오류 뒤 기존 이미지·문구·템플릿이 사라지거나, 미리보기와 다운로드 결과가 다르면 실패입니다.

## AI와 내 판단 3줄 (권장)

AI에게 맡긴 일: Canvas 공통 렌더러, 이미지 파일 검증, 자동 줄바꿈과 경계 보정, 템플릿 CRUD·JSON schema 검증, 반응형 미리보기, 자동 테스트와 검증 문서 구현을 맡겼습니다.

내가 판단한 일: 세 화면비의 출력 크기, 문구의 상대 좌표와 안전 여백, 한국어 오류 UX, 테스트 문구·이미지 구성, 공개 자료와 로컬 보관 자료의 범위를 과제 요구에 맞게 결정했습니다.

AI 말을 안 들은 일: AI 제안을 따르지 않은 일은 없었으며, 제안을 직접 검토하고 실제 브라우저 테스트에서 발견한 미리보기 잘림과 텍스트 경계 문제를 반복 확인한 뒤 과제 요구사항에 맞는 내용만 적용했습니다.
