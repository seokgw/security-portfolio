# PAIR UP!

같은 그림의 카드 두 장을 찾아 점수를 얻는 30초 메모리 카드 게임입니다. HTML, CSS, Vanilla JavaScript만 사용하며 별도 로그인·백엔드·외부 API가 없습니다.

## 게임 규칙

- 카드 두 장을 선택합니다.
- 같은 그림이면 100점을 얻습니다.
- 모든 카드 쌍을 찾으면 CLEAR입니다.
- 제한시간 30초가 끝나면 TIME OVER입니다.

## 조작 방법

마우스로 카드를 클릭합니다. 게임 중 `일시정지`, `다시 시작`, `기록 초기화`를 사용할 수 있습니다.

## 실행 방법

`index.html`을 브라우저에서 직접 열거나, 프로젝트 폴더에서 정적 서버를 실행합니다.

```bash
python -m http.server 8000
```

그다음 `http://localhost:8000`에 접속합니다. GitHub Pages에서는 저장소의 Pages 주소로 바로 접속합니다.

## 핵심 상태 설계

- 현재 판의 점수, 시간, 카드 배열, 선택 카드, 매칭 상태는 메모리에만 존재하며 재시작 때 초기화됩니다.
- `localStorage`에는 `bestScore`, `totalGames`, `totalWins`만 저장합니다.
- 저장값이 없거나 JSON/타입/숫자 조건이 잘못되면 `{ bestScore: 0, totalGames: 0, totalWins: 0 }`으로 복구합니다.
- 타이머와 비교 대기 타이머는 재시작 및 종료 시 모두 정리합니다.
- 포커스 이탈이나 수동 일시정지 중에는 시간과 카드 비교가 진행되지 않습니다.

### 최종 난이도 판단

각 난이도의 성공·실패 횟수, 성공한 판의 클리어 시간 중앙값, 점수 범위, 반복된 실패 원인을 비교해 최종값을 선택합니다. 아래 문장은 형식 예시이므로 실제 기록에 맞게 반드시 수정합니다.

> 12장에서는 10회 중 10회 성공했고 클리어 시간 중앙값이 17초였다. 16장에서는 10회 중 7회 성공했고 중앙값이 25초였다. 실패 3회는 마지막 카드 쌍을 찾지 못해 발생했다. 따라서 성공 가능성과 도전성을 함께 고려해 16장을 선택했다.

## Git 및 GitHub Pages 배포

이미 상위 폴더가 Git 저장소라면 다시 `git init`하지 않습니다. 이 폴더만 별도 저장소로 올릴 때는 다음 순서로 진행합니다.

```bash
git init
git add .
git commit -m "feat: create memory card game"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

GitHub 저장소의 `Settings → Pages → Build and deployment`에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다. 배포 후 아래 주소를 시크릿 창에서 열어 로그인 없이 표시되는지 확인합니다.

- 결과물: `https://USERNAME.github.io/REPOSITORY/`
- 소스: `https://github.com/USERNAME/REPOSITORY`

## 제출용 확인 방법

1. 위치: GitHub Pages 게임 주소로 접속합니다.

2. 행동: 게임을 시작하고 카드 두 장을 선택해 같은 그림의 카드를 맞춥니다.
