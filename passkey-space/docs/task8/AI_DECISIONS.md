# AI와 내 판단 3줄

① AI에게 맡긴 일: WebAuthn 등록·로그인·세션·권한 검증 구현, 테스트 코드와 배포 스크립트 작성, 실제 결과 정리.

② 내가 직접 판단한 일: 공개 소개를 유지하고 비공개 영역만 보호한다는 요구, README 등 문서를 새 폴더에 저장하는 방식, 기존 다이어리 서버 사용을 지정했다.

③ AI 제안을 따르지 않은 일: 별도로 거절한 기술 제안은 현재 대화에 없다. 세부 선택을 모두 직접 검토했다고 볼 근거는 없으므로, 제출자는 구현과 검증 결과를 직접 확인한 뒤 본인의 수용 이유를 보완한다.
