# 과제 4 제출 확인문

위치: https://seokgw.github.io/security-portfolio/t04-real-information-board/ — 현재 실제 정보, 실제 일별 기록, 합성 장애 실험실을 한 페이지에서 확인합니다.

행동: ① `실제 값 조회` ② 합성 상태 초기화 후 D1-A·D1-B와 실패 버튼 ③ `다시 시도 / 복구`를 누릅니다.

통과 모습: 값·°C·Open-Meteo·출처 시각·조회 시각·Asia/Seoul이 보이고, 실제 KST 날짜 2026-08-27의 30.2°C와 2026-08-28의 25.2°C가 정확히 2건 보존되며 어제 대비는 `25.2 − 30.2 = -5°C`로 표시됩니다. replay는 D1-B까지 1행/105, 복구 후 2행/120/+15와 fresh/none입니다.

안 될 때 모습: timeout·외부 401/403·429·offline·schema_error별 설명과 다음 행동이 다르게 보이며, 마지막 정상값 105에는 stale·오래된 값 표시와 다시 시도 버튼이 붙습니다.

AI에게 맡긴 일: 데이터 모델, KST upsert, 오류 상태 분리, fixture adapter, UI와 자동 테스트 구현을 맡겼습니다.

내가 직접 판단한 일: 공개 원천으로 Open-Meteo 서울 현재 기온, 단위 °C, 절대 변화량 계산, 실제/합성 저장소 분리 UX를 선택하고 최종 결과를 검토합니다.

AI 제안을 따르지 않은 일: 실제 기록을 합성 D1/D2 값으로 대신하지 않고, 서로 다른 실제 KST 날짜에 Open-Meteo를 직접 조회한 30.2°C와 25.2°C만 최종 증거로 채택했습니다.
