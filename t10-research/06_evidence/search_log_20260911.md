# 보충 탐색 기록

일자 2026-09-11. 기존 ZIP의 5개 원자료를 기본으로 한 제한된 보충검색이다. 체계적 문헌고찰이나 전체 데이터베이스 전수 검색이 아니다.

검색어: 병사 휴대전화 허용 스트레스 복무염증 연구 스마트폰 2018 시범 운용 실태 조사 / 군 복무 병사의 회복탄력성 스마트폰 2020 / site.kci.go.kr 휴대전화 스트레스 병사 허용 전후 / site.kci.go.kr 휴대전화 복무염증.

KCI ART002661556 공식 초록과 서지는 직접 열람. 이용 동기·과의존·군 생활 적응 연구였으나 정책 허용의 전후 효과나 복무염증 감소량을 확인하지 못해 채택하지 않았다. 2018 보고서는 ZIP 원본 11쪽을 모두 판독. 추가 검색에 나타난 언론기사·대학생 연구·무관한 결과는 핵심 근거로 사용하지 않았다. 새로 확인한 직접 인과·매개 검정 자료는 없다. 검색결과의 발행일 표시를 원자료 발행일로 채택하지 않았다.
