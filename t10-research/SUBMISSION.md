## 재현 및 통과 확인

어디서 확인하나요: 제출 ZIP의 04_analysis/README.md와 06_evidence/T10_C01_C51_checklist.md를 확인합니다.

무엇을 하나요: 1) ZIP을 풀고 Python 라이브러리를 설치합니다. 2) python 04_analysis/analysis.py를 실행합니다. 3) python 04_analysis/verify_results.py를 실행합니다.

무엇이 보이면 통과인가요: 6개 지표의 12개 집계값과 표·그림이 생성되고 검증 코드가 PASS를 출력합니다. 외부 소통 차이는 +0.2%p, 심리적 안정 차이는 +0.1%p입니다. 이는 인식 비율의 차이이며 스트레스 감소율이 아닙니다.

안 될 때: Python과 requirements.txt의 라이브러리 설치, 원본 PDF의 경로를 확인합니다. 상세 실행법과 수동 확인법은 04_analysis/README.md를 참고합니다.
